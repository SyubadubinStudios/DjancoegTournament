## Download / Unduh

| Platform | File |
|---|---|
| Windows 10/11 x64 | `DjancoegTournament-Setup-win-x64.exe` (installer) · `DjancoegTournament-win-x64-portable.zip` |
| Linux x64 | `DjancoegTournament-x86_64.AppImage` · `djancoeg-tournament_amd64.deb` · `DjancoegTournament-x86_64.flatpak` · `DjancoegTournament-linux-x64.tar.gz` |
| macOS 12+ Apple Silicon | `DjancoegTournament-macOS-arm64.dmg` |
| macOS 12+ Intel | `DjancoegTournament-macOS-x64.dmg` |

No .NET install needed. Installers are not code-signed or notarized yet:

- **Windows:** SmartScreen → *More info → Run anyway*.
- **macOS:** right-click the app → *Open*, or run `xattr -dr com.apple.quarantine "/Applications/Djancoeg Tournament.app"`.
- **Linux AppImage:** `chmod +x` it first.

Verify downloads with `SHA256SUMS.txt`.

Tidak perlu memasang .NET. Installer belum ditandatangani:

- **Windows:** pilih *More info → Run anyway*.
- **macOS:** klik kanan aplikasi → *Open*.
